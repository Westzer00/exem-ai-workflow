# 최종 발표 화면 자료

EXEM × ASAC 최종 발표의 PHISIGHT 소개 화면(37페이지)과 사람 검토 화면(40페이지)을 이미지로 저장했습니다.

- `phisight-ui-overview.webp`: 운영 화면·데이터 현황의 시각 구성
- `phisight-human-review.webp`: 검토 대기·판정 사유·사람 확인 단계의 화면 구성(상세 결과 텍스트 흐림 처리)

두 이미지는 **UI 설명용 미리보기**입니다. 이 저장소의 LOOP 독립 예제 코드와 실제 PHISIGHT 서비스 원본 화면은 서로 다른 결과물입니다.

실제 피싱 음성·문자 원문, 협업 기관의 명칭, 내부 서버 주소·계정과 원본 고객 데이터는 공개하지 않습니다. 서비스의 실제 운영·보안·실시간 처리 검증을 증명하는 사진은 아닙니다.
