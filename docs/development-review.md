# 사내 개발 절차와 코드 리뷰 근거

## 담당 업무와 변경 범위
EXEM × ASAC 기업연계 프로젝트 중 **eXemble LOOP 입출력 개선**을 담당했습니다. 사내 개발 배분안에 개발자 A(김서영)의 담당 기능으로 기재되어 있으며, AIG-8496~8499 작업본에서 Python 실행 로직과 테스트 코드를 확인할 수 있습니다.

1. 문제 발견: 반복 실행은 가능했지만 하위 노드의 여러 결과를 다음 회차에 구분하여 전달하기 어려웠음
2. 설계: 반복 외부 입력과 내부 출력의 경계를 정하고 출력에 별칭을 부여
3. 작업 분해: LOOP 입력·출력, 이전 회차 결과 참조, 종료 조건 및 예외 검증
4. 백엔드 수정: 기존 Python 워크플로우 실행 로직을 수정하고 관련 테스트 코드 작성
5. 사내 리뷰: 회사 Git의 PR·코드 리뷰 절차에서 피드백을 반영하여 작업

## 코드에서 확인된 구현
- input_bindings 해석 및 반복에 입력 전달
- output_bindings로 내부 출력 별칭 관리
- previous_round, rounds, last_round 데이터 전달·보관
- 선택한 출력에 대한 종료 조건과 잘못된 참조·하위 노드 오류 처리
- 앞선 회차 데이터가 변경되지 않도록 값 복사

사내 제품 원본은 공개하지 않았습니다. [독립 실행 예제](../backend/loop_demo/engine.py)는 구조를 새로 재현한 코드입니다.
