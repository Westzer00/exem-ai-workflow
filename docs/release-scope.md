# 공개 범위

**공개:** 개인이 별도로 구현한 LOOP 예제, 합성 데이터, 테스트, 고수준 구조 설명과 개인 담당 범위, 팀 최종 발표에 사용한 PHISIGHT 예시 화면(개인정보·원본 데이터 제외).

**비공개:** EXEM 원본 eXemble 코드, PHISIGHT 팀 UI·서버 전체, 실제 통화·문자 자료, 내부 주소·비밀키·프롬프트, ClickUp 원문, 내부 Git PR 원문·검토 댓글 및 외부 공개 승인되지 않은 워크플로우 설정·화면.

이 저장소의 코드는 원본 플랫폼과 동일한 구현이 아닙니다. 합성 데이터 예제의 성공을 기업 제품 전체의 통합 테스트·운영 성공으로 소개하지 않습니다.

**UI 이미지 출처:** EXEM × ASAC 최종 발표 자료의 37·40페이지 미리보기입니다. 실제 화면 UI를 소개하는 자료이며 실데이터 분석 결과나 운영 서비스 배포 증거로 사용하지 않습니다.
