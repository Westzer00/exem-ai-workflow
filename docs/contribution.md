# 개인 기여와 팀 성과 구분

| 구분 | 작업 |
|---|---|
| **개인 담당** | eXemble LOOP 입출력 개선안과 Python 백엔드 데이터 전달·종료 조건 로직 개발, 테스트 |
| **개인 참여** | STT 검수 로직·화자 정렬·사람 검토 화면 (별도 STT 저장소) |
| **공동 개발** | PHISIGHT 초기 UI 구조·사용자 흐름 설계, 2인 상세 UI 구현 |
| **팀 성과** | 보이스피싱·스미싱 검색·분류·생성·검수 워크플로우 및 데이터 구축 |
| **공개용 독립 예제** | 합성 데이터를 사용하는 Python LOOP·HTTP API·웹 화면·테스트 |

기업 내부 개발 배분안과 실제 백업 코드로 LOOP 담당 및 백엔드 작업을 확인했습니다. 새 입력·출력 설정 UI의 제품 반영과 실제 운영 배포 완료는 별도로 입증하지 않았습니다.

## 기업 개발 절차

사내 ClickUp에서 LOOP 입출력 개선 기능을 개인 담당으로 배정받고, 요구사항·하위 작업을 정리한 뒤 회사 Git에서 구현과 PR·코드 리뷰를 진행했습니다. 내부 개발 기록은 외부 채용 담당자가 바로 열어볼 수 없으므로 [개발·리뷰 절차 문서](development-review.md)에 확인 가능한 범위만 요약했습니다.

공공기관 협업 과제라는 프로젝트 성격은 소개하되 구체적인 협업기관과 원본 데이터 제공처는 공개하지 않습니다. 실제 공공기관 현장 도입은 확인되지 않은 성과로 적지 않습니다.
